# Изменения

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [1.0.1] — 2026-08-26

### Изменено

- Главным README стал английский: npmjs.com и GitHub Packages рендерят только
  `README.md` и про языковые варианты не знают, поэтому на страницу пакета
  уезжало русское описание. Русская версия переехала в `README.ru.md`.
- Поле `description` в package.json переведено на английский: именно оно
  попадает в выдачу поиска npm.

## [1.0.0] — 2026-08-23

Первый публичный выпуск.

### Добавлено

- Проверка SMTP из консоли: TCP-подключение, implicit TLS и STARTTLS, EHLO,
  аутентификация (PLAIN, LOGIN, CRAM-MD5, XOAUTH2) и отправка тестового письма.
- Пресеты популярных провайдеров и автоопределение по домену адреса (`--list`).
- Режимы `--probe` (какие порты открыты), `--dry-run` (итоговые настройки без
  подключения), `--json` (машинночитаемый результат) и `--verbose` (диалог с сервером).
- Расшифровка ошибок с подсказками на русском и английском.
- Программный интерфейс (`checkSmtp`) и декларации типов `index.d.ts`.
- Ноль runtime-зависимостей: только `node:net`, `node:tls`, `node:crypto`.

### Исправлено

- `--send` без отправителя или получателя падал внутри SMTP-сессии с
  `TypeError: Cannot read properties of null`. Теперь это ошибка конфигурации
  с понятным текстом, до подключения.
- Вход без `--user` отправлял на сервер логин `null` и получал невнятный ответ
  535. Теперь запрашивается логин или явный `--no-auth`.
- Нечисловые `--port`, `--timeout` и `--ports` превращались в `NaN`: таймаут
  срабатывал мгновенно, а в отчёте значилось «за NaN мс». Значения проверяются
  при разборе аргументов.
- Адреса в `--from` и `--to` проверяются на явный мусор до `MAIL FROM`.
- Код выхода выставляется через `process.exitCode` вместо `process.exit()` —
  при перенаправлении вывода (`--json > out.json`) хвост больше не теряется.
- Раскраска сообщений об ошибках определяется по stderr, а не по stdout.
